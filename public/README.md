# Login background image

To show a photo behind the left panel of the login page, save an image here named:

    login-bg.jpg

Recommendations:
- A doctor / hospital / clinical photo works well.
- Use a free, licensed source (e.g. Unsplash or Pexels) — safe for a report.
- Landscape orientation, at least 1200×1600px, looks best.

The page already applies a dark teal gradient over the image so the white
heading and text stay readable. If no `login-bg.jpg` is present, the login page
simply falls back to the solid gradient background — nothing breaks.
